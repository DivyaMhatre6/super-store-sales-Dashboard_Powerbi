📊 Super Store Sales Dashboard – Power BI

The Super Store Sales Dashboard is an interactive Business Intelligence project developed using Microsoft Power BI to analyze retail sales data and generate meaningful business insights. The dashboard visualizes key performance metrics such as sales, profit, customer segments, and regional performance to support data-driven decision-making.

🚀 Project Overview

This project focuses on transforming raw sales data into an interactive dashboard that helps understand business trends, product performance, and profitability across different regions and categories.

🎯 Objectives
Analyze overall sales and profit performance
Identify top-performing products and categories
Track regional and state-wise sales trends
Understand customer purchasing behavior
Provide actionable business insights through visualization

📌 Features
Interactive Power BI dashboard
Sales & Profit KPI indicators
Category and Sub-category analysis
Region-wise performance visualization
Monthly and yearly sales trend analysis
Dynamic filters and slicers
